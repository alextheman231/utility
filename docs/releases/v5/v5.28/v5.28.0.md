## Description of Changes

<!-- user-editable-section-start -->
- Add the following functions:
  - `secondsToMs`
  - `minutesToMs`
- Both of the above take a given common time unit and convert it into milliseconds.
- This is helpful as minutes/seconds tend to be easier to parse for humans whereas a lot of date/time utilities may tend to prefer milliseconds.
- As such, having these functions here makes call sites in these situations easier to read so that we don't need to either specify the raw milliseconds or do `* 60 * 1000` manually everywhere.
