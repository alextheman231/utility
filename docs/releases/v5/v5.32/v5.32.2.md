## Description of Changes

<!-- user-editable-section-start -->
- Migrate linting setup to `oxlint` and address reported issues.
  - We are doing a very heavy linting migration throughout all of our projects, from ESLint to Oxlint.
  - The benefit of this is that Oxlint is faster and requires less manual installation of plugin dependencies.
  - In the case of this repository it has flagged a few things like unsafe type casts, misused spreads and more.

## Additional Notes

- Note that not every single rule got ported over, but I wasn't expecting it to because our linting setup was very complex previously.
- That said, I think it's a fine trade-off because I can add any rules back that feel like they should be there, and if I don't notice it probably wasn't important enough anyway.
