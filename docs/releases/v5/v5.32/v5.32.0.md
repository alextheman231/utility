# v5.32.0 (Minor Release)

<!-- alex-c-line-release-status-start -->
**Status**: Released
<!-- alex-c-line-release-status-end -->

<!-- alex-c-line-release-summary-start -->
This is a new minor release of the `@alextheman/utility` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Change the Zod peer dependency to `>=4.6.6`
  - Anything less than this version is a vulnerable version of Zod as per [this security advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).
  - It affects parts of the code where we parse arrays without specifying an extra maximum constraint, which in our case is fairly often.
  - As such, to remain safe, it is best to enforce that consumers also don't use the vulnerable Zod version, hence the updated peer dependency pin.

## Additional Notes

- This is a minor release because it may potentially require users to update their dependency tree.
- If they are already on higher than v4.6.6, users shouldn't have to take any further action, but if they aren't they'd have to update their Zod version and deal with any errors as a result of updating.
