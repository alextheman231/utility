This is a new minor release of the `@alextheman/utility` package. It introduces new features and other backwards-compatible changes that should require little to no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Remove the v6 `APIError`.
  - Since it is part of an experimental v6 entrypoint and is only used in one project I am comfortable just removing it entirely and dealing with the hard errors.
  - For my use cases it now makes more sense for `APIError` to be defined within Lexicon itself rather than here, as it feels more domain-specific. It removes a lot of maintenance cost for me.
- Update deprecation messages for existing `APIError` class.
  - As it is no longer intended to be supported at all so should not point to the v6 version.
