This is a new patch release of the `@alextheman/utility` package. It includes small, non-breaking changes and should require no refactoring. Please read the description of changes below.
<!-- alex-c-line-release-summary-end -->

## Description of Changes

<!-- user-editable-section-start -->
- Minor refactors to `VersionNumber`
  - It behaves in exactly the same way as before but the code has been rewritten slightly to be cleaner.
    - A switch case is used for the version type selection for better type safety as it no longer requires the type cast.
    - We now also use the `checkWithCode` property rather than the regular check followed by the manual code check for the `NEGATIVE_INPUTS` error, as that also accounts for the type narrowing of the code natively.

## Additional Notes

- All of the above changes are internal and do not require users to change their code. No behavioural differences are expected as a result of this change.
