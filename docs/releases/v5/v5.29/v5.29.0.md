## Description of Changes

<!-- user-editable-section-start -->
- Rename `CreateEnumType` to `ObjectValue`.
  - This better reflects what it actually does - it gets the value type from the object type. Getting an enum type is just one application of this.
  - For now it has been deprecated so existing usage doesn't break. In the next major release it will be removed entirely.
